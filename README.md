# CROSS FINAL

架空の地球上に、作品を越えて人物を配置・検索・接続するローカルPWAです。

## 完成版の主な機能
- ホログラム調の架空地球
- 指についてくる順方向の地球回転
- MOVE MODE中のみ人物座標を移動
- 空いている地表の長押しで、その座標に人物追加
- 人物情報：名前 / 作品名 / 性別 / 年齢 / 職業 / 詳細 / 島
- 名前・作品検索、作品・島フィルタ
- 検索式の人物接続、放物線アーク表示
- 島名変更
- 小 / 中 / 大の島追加
- 設定内の使い方ガイド
- 一撃の鑑賞モード
- ローカル保存、JSONバックアップ

既存v0.1の保存データは同じURL・同じブラウザなら自動移行します。
