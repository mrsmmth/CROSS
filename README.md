# THREE PITCH v3.0

## ハモモード
- 選択コードの構成音をMELODY上で発光表示
- コード外音を選ぶと警告
- 基本三和音から上方向・下方向の最短ハモを表示
- 装飾音は本命計算に使わず「もしかして？」へ表示

## コード生成モード
- 聞こえた音を複数選択
- 前後コードを任意入力
- 音の一致度、余分な音、共通音、ルート進行をローカル計算
- 可能性が高い順にコード候補を表示
- Web検索・通信不要

GitHub Pagesへ全8ファイルを上書きしてください。既存のホーム画面アイコンはURLが同じなら追加し直す必要はありません。

- v3.1: 主旋律またはコードを選び直した際、コード内音なら警告表示が即時消えるよう修正。
