# CROSS FINAL v1.1

架空の地球上に、作品を越えて人物を配置・検索・接続するローカルPWAです。

## 主な機能
- ホログラム調の架空地球
- 指についてくる順方向の地球回転
- 通常画面では人物座標を完全ロック
- VIEWで人物を長押し→ドラッグすると球面移動
- VIEWで空き地表を長押しすると、その座標に人物追加
- VIEW専用の深いズーム（最大2.85倍）
- 通常画面とVIEWでズーム倍率を別々に保持
- 人物情報：名前 / 作品名 / 性別 / 年齢 / 職業 / 詳細 / 島
- 名前・作品検索、作品・島フィルタ
- 検索式の人物接続、放物線アーク表示
- 島名変更
- 小 / 中 / 大の島追加
- 設定内の使い方ガイド
- ローカル保存、JSONバックアップ

既存版の保存データは同じURL・同じブラウザなら自動移行します。
